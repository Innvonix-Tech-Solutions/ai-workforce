Netlist, Inc. (OTCQB: NLST) is a premier designer and manufacturer of high-performance memory subsystems and persistent storage architectures, headquartered in Irvine, California. Founded in 2000 by Chairman and CEO C.K. (Chuck) Hong, Netlist pioneered foundational server memory technologies, including Load-Reduced DIMM (LRDIMM) rank multiplication, hybrid storage-class memory (HybriDIMM and NVvault), and CXL-attached persistent memory. Operating at the intersection of advanced hardware engineering and high-value intellectual property, Netlist has established a portfolio of 130+ issued and pending global patents that underpin standard server architectures across the computing industry. Its breakthrough portfolio spans CXL NVvault Type 3 memory pooling platforms, Lightning Ultra-Low Latency DDR5 RDIMMs delivering 10-12% lower memory latency for AI workloads, enterprise NVMe Gen4/Gen5 SSDs, and multi-hundred-million-dollar global patent licensing and supply agreements with industry leaders such as Micron, Samsung, and SK Hynix.
